# Learning HADS

Short explanations for contributors who want to understand a concept and why it matters here. Current examples describe the planned architecture; application code is not implemented yet. Introduced in [HADS-5](../../tracker/HADS-5.md).

## Find the right kind of answer

Learning guides explain concepts with HADS examples. The [decision register](../decisions.md) records actual choices and tradeoffs. [Rules](../../rules/README.md) define mandatory behavior. [API](../../api-design/README.md) and [database](../../database-design/README.md) documents define contracts. The [hosting guide](../setup-and-hosting.md) contains setup instructions.

A tutorial does not approve a feature or replace these sources. For the contributor procedure, start with the [development workflow](../../rules/workflow.md). Guide creation and maintenance conventions live in [repository rules](../../rules/repository.md#learning-guides).
